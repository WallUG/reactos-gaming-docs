# Glosario Técnico

Esta página define los términos técnicos utilizados en la documentación de ReactOS Gaming.

## A

| Término | Definición |
|---------|------------|
| ACPI | Advanced Configuration and Power Interface. Especificación para gestión de energía y configuración de hardware. |
| API | Application Programming Interface. Interfaz de programación de aplicaciones. |
| API Set | Mecanismo de Windows para redireccionar llamadas a DLLs específicas según la versión del sistema. |
| ARN (Arnés de Regresión) | Conjunto de herramientas para ejecutar suites de pruebas y detectar regresiones en ReactOS Gaming. |
| ASLR | Address Space Layout Randomization. Técnica de mitigación de exploits que aleatoriza la ubicación de regiones de memoria. |

## B

| Término | Definición |
|---------|------------|
| BCD | Boot Configuration Data. Datos de configuración de arranque de Windows. |
| BSOD | Blue Screen of Death. Pantalla azul de error crítico del sistema. |

## C

| Término | Definición |
|---------|------------|
| CC | Cache Manager. Componente del núcleo que gestiona el caché de archivos. |
| CDFS | Controlador de sistema de archivos ISO9660 (CD/DVD). |
| Cm | Configuration Manager. Componente del núcleo que gestiona el registro. |
| COM | Component Object Model. Modelo de objetos de componentes de Microsoft. |
| CPL | Control Panel Library. Biblioteca del Panel de Control. |
| CR0, CR2, CR3, CR4 | Registros de control del procesador x86. |
| CSRSS | Client/Server Runtime Subsystem. Subsistema de runtime de cliente/servidor. |

## D

| Término | Definición |
|---------|------------|
| DDI | Device Driver Interface. Interfaz de controlador de dispositivo. |
| DWM | Desktop Window Manager. Gestor de ventanas de escritorio de Windows Vista+. |
| DXGKRNL | Núcleo del modelo WDDM. |
| DXVK | Capa de traducción de Direct3D a Vulkan. |

## E

| Término | Definición |
|---------|------------|
| EHCI | Enhanced Host Controller Interface. Controlador de host USB 2.0. |
| EISA | Enhanced Industry Standard Architecture. |
| EPT | Extended Page Table. Tablas de página extendidas para virtualización. |
| ETW | Event Tracing for Windows. Sistema de trazado de eventos de Windows. |

## F

| Término | Definición |
|---------|------------|
| FAT | File Allocation Table. Sistema de archivos de Microsoft. |
| FDO | Function Device Object. Objeto de dispositivo funcional en la pila de controladores. |
| FSD | File System Driver. Controlador de sistema de archivos. |

## G

| Término | Definición |
|---------|------------|
| GDI | Graphics Device Interface. Interfaz de dispositivo gráfico de Windows. |
| GPU | Graphics Processing Unit. Unidad de procesamiento gráfico. |
| GUEST | Sistema operativo invitado en una máquina virtual. |

## H

| Término | Definición |
|---------|------------|
| HAL | Hardware Abstraction Layer. Capa de Abstracción de Hardware. |
| HDA | High Definition Audio. Audio de alta definición. |
| HID | Human Interface Device. Dispositivo de interfaz humana (teclado, ratón). |
| HPET | High Precision Event Timer. Temporizador de eventos de alta precisión. |

## I

| Término | Definición |
|---------|------------|
| ICD | Installable Client Driver. Controlador de cliente instalable (OpenGL). |
| IDT | Interrupt Descriptor Table. Tabla de descriptores de interrupciones. |
| IFS | Installable File System. Sistema de archivos instalable. |
| IIR | Interrupt Identification Register. Registro de identificación de interrupciones. |
| IRP | I/O Request Packet. Paquete de solicitud de entrada/salida. |
| IRQL | Interrupt Request Level. Nivel de prioridad de interrupción. |
| ISA | Industry Standard Architecture. |

## K

| Término | Definición |
|---------|------------|
| KDB | Kernel Debugger. Depurador del núcleo de ReactOS. |
| KSE | Kernel Shim Extension. Extensión de shim del núcleo para version lie. |
| KTHREAD | Estructura de hilo del kernel. |

## L

| Término | Definición |
|---------|------------|
| LPC | Local Procedure Call. Llamada a procedimiento local. |
| LSASS | Local Security Authority Subsystem Service. Servicio de autoridad de seguridad local. |
| LUN | Logical Unit Number. Unidad lógica en almacenamiento. |

## M

| Término | Definición |
|---------|------------|
| Mm | Memory Manager. Gestor de memoria del núcleo. |
| MSR | Model Specific Register. Registro específico del modelo del procesador. |
| MTBF | Mean Time Between Failures. Tiempo medio entre fallos. |

## N

| Término | Definición |
|---------|------------|
| NDI | Network Driver Interface. Interfaz de controlador de red. |
| NDIS | Network Driver Interface Specification. Especificación de interfaz de controlador de red. |
| NMI | Non-Maskable Interrupt. Interrupción no enmascarable. |
| NTDLL | Biblioteca nativa de Windows NT (ntdll.dll). |
| NTOSKRNL | Núcleo del sistema operativo Windows NT (ntoskrnl.exe). |
| NVDA | Firma de NVIDIA en datos privados de asignaciones de video. |
| NVKM | Firma de NVIDIA Kernel Mode en datos privados. |

## O

| Término | Definición |
|---------|------------|
| OHCI | Open Host Controller Interface. Controlador de host USB 1.1. |
| OOB | Out Of Band. Fuera de banda. |
| OPP | Operating Performance Points. Puntos de operación de rendimiento. |

## P

| Término | Definición |
|---------|------------|
| PAE | Physical Address Extension. Extensión de dirección física (para >4 GB de RAM). |
| PAGED | Memoria paginable. |
| PBM | Power Button Manager. Gestor de botón de encendido. |
| PDO | Physical Device Object. Objeto de dispositivo físico. |
| PE | Portable Executable. Formato de ejecutable de Windows. |
| PFN | Page Frame Number. Número de marco de página. |
| PIO | Programmed Input/Output. Entrada/salida por programa. |
| PnP | Plug and Play. Detección automática de hardware. |
| PPM | Processor Power Management. Gestión de energía del procesador. |
| PRAMIN | Ventana de memoria de la GPU NVIDIA para acceso directo a VRAM. |
| PS | Process and Thread Manager. Gestor de procesos e hilos. |
| PTE | Page Table Entry. Entrada de tabla de página. |

## Q

| Término | Definición |
|---------|------------|
| QEMU | Quick Emulator. Emulador y virtualizador de máquinas. |

## R

| Término | Definición |
|---------|------------|
| RDRAM | Rambus DRAM. |
| ROS | ReactOS. |
| ROSAPPS | Aplicaciones de ReactOS. |
| ROSTESTS | Tests de regresión de ReactOS. |
| RTC | Real-Time Clock. Reloj en tiempo real. |

## S

| Término | Definición |
|---------|------------|
| SAM | Security Accounts Manager. Gestor de cuentas de seguridad. |
| SATA | Serial ATA. Interfaz de almacenamiento en serie. |
| SCSI | Small Computer System Interface. Interfaz de sistemas pequeños de computadora. |
| SDT | System Descriptor Table. Tabla de descriptores del sistema. |
| SEH | Structured Exception Handling. Manejo de excepciones estructuradas. |
| SMB | Server Message Block. Protocolo de compartición de archivos. |
| SMP | Symmetric Multiprocessing. Procesamiento multiprocesador simétrico. |
| SMSS | Session Session Manager. Gestor de sesiones de Windows NT. |
| SPD | Serial Presence Detect. Detección de presencia en serie (memoria RAM). |
| SSDT | System Service Descriptor Table. Tabla de descriptores de servicios del sistema. |
| STOP | Código de error crítico de Windows (BSOD). |
| SVGA | Super Video Graphics Array. Estándar de gráficos de video. |
| SW | Software. |
| SWENUM | Software Enumerator. Enumerador de dispositivos de software. |
| SYS | Extensión de archivo para controladores de sistema Windows (.sys). |

## T

| Término | Definición |
|---------|------------|
| TLB | Translation Lookaside Buffer. Caché de traducción de direcciones. |
| UAC | User Account Control. Control de cuentas de usuario. |
| UDMA | Ultra DMA. Modo de transferencia de disco rápido. |
| UEFI | Unified Extensible Firmware Interface. Interfaz de firmware extensible unificada. |
| USB | Universal Serial Bus. Bus serie universal. |
| UUID | Universally Unique Identifier. Identificador único universal. |

## V

| Término | Definición |
|---------|------------|
| VAD | Virtual Address Descriptor. Descriptor de dirección virtual. |
| VBE | VESA BIOS Extensions. Extensiones de BIOS de VESA. |

| VGA | Video Graphics Array. Estándar de gráficos de video. |
| VHD | Virtual Hard Disk. Disco duro virtual. |
